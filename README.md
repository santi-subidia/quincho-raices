# 🌿 Quincho Raíces — Landing Page Oficial

> **El lugar para tu evento** · B° Aires de San Benito, La Punta, San Luis, Argentina.

Landing page moderna, fluida y con identidad botánica-serrana diseñada y desarrollada para **Quincho Raíces**, espacio exclusivo para celebraciones, reuniones y eventos de hasta 40 personas al pie de las Sierras de San Luis.

---

## ✨ Características Principales

- **Diseño Inspirado en el Paisaje Serrano**:
  - Siluetas topográficas y vectoriales de las Sierras de San Luis en transiciones día-a-noche.
  - Guía visual interactiva de raíces botánicas animadas al compás del scroll (`ScrollRoots`).
  - Partículas ambientales sutiles y efectos de resplandor atardecer (*twilight sunset glow*).
  - Tipografía editorial equilibrada (`Playfair Display` + `Plus Jakarta Sans`).
- **Cotizador Interactivo de Presupuestos**:
  - Selección de tipo de evento, cantidad de invitados, servicios opcionales (vajilla, sonido, leña/carbón).
  - Generación en tiempo real del mensaje estructurado para WhatsApp con un solo clic.
- **Galería Fotográfica Curada**:
  - Muestra visual del parque, piscina con vistas a las sierras, quincho cerrado, churrasquera/parrilla e instalaciones.
- **Ubicación Verificada**:
  - Mapa interactivo integrado con enlace directo a Google Maps y coordenadas exactas.
- **Rendimiento y Accesibilidad**:
  - Desarrollado sobre arquitectura estática (SSG) de **Astro** para carga instantánea.
  - Adaptabilidad total en dispositivos móviles con inputs de 16px para evitar zoom indeseado en iOS Safari.
  - Micro-interacciones optimizadas (`spotlight-card`, acordeón FAQ zero-CLS, animaciones con respeto a `prefers-reduced-motion`).

## 🚀 Inicio Rápido

### Prerrequisitos
- Node.js 18+ o superior
- npm / pnpm / yarn

### Instalación

```bash
# Clonar el repositorio
git clone https://github.com/santi-subidia/quincho-raices.git

# Entrar al directorio
cd quincho-raices

# Instalar dependencias
npm install
```

### Comandos Disponibles

| Comando | Descripción |
| :--- | :--- |
| `npm run dev` | Inicia el servidor de desarrollo local en `http://localhost:4321` |
| `npm run build` | Compila el sitio estático de producción en la carpeta `dist/` |
| `npm run preview` | Previsualiza la versión compilada de producción localmente |
